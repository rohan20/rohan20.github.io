# rohan20.github.io
Personal Website: www.rohantaneja.com

## Agent-readable public content

Run `python3 scripts/generate-agent-content.py` from the repository root after editing public page content.
Commit the regenerated Markdown with its source HTML so both formats stay in sync.
`agent-content.json` lists the intended public pages; unlisted drafts are not exported.
GitHub Pages serves the Markdown sidecars and HTML discovery metadata. It does not support custom response
headers or Accept-based content negotiation; those require a separate hosting change.
